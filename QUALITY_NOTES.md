# Quality review and protocol clarifications

These are data-quality clarifications, not changes chosen to improve the study's headline.

- **Complete game coverage:** 2,216/2,216 expected completed FBS-vs-FBS regular-season games have play records. Within-game completeness is not guaranteed. All raw plays joined to a downloaded schedule game.
- **Missing PPA:** 285,315 eligible offensive plays, 284,804 measured PPA values. Missing values stay missing. Chart games require 20 measured plays and 90% coverage.
- **Drive identity:** 78 drive IDs contain eligible plays from both offenses. Exclude those IDs from drive metrics. Also exclude 53 remaining play/drive offense mismatches. These records remain usable for game PPA when the offensive team is identified in the play record. Adjacent snap intervals require the same offensive team.
- **Drive outcomes:** 242 Uncategorized and 22 other ambiguous outcome labels do not receive guessed points. Conservative drive outcome mapping includes explicit offensive TDs and field goals only. 48,692 drives pass the combined filters.
- **Clock:** elapsed possession time is provider-reported and includes excluded administrative/special-teams clock. The clean in-bounds subset additionally requires explicit tackle text, no out-of-bounds/first-down wording and consecutive eligible records in one period. It contains only 3,937 intervals and is not representative of all snaps; missing subset summaries must not be treated as zero.
- **Score timing:** sampled scoring records are post-play. Garbage-time filtering uses preceding observed scores across all game records before excluding plays. Sorting tied clocks and incomplete records can still introduce errors. The tested cutoff excludes the next play after a score crosses 28, not the scoring play itself.
- **Calendar:** use America/Chicago game dates for intervention comparisons. The pilot's UTC-date display is historical and superseded by the expanded study. CFBD includes conference championships under regular-season classification; Boise State therefore has three follow-up games, still fewer than four.
- **Reference stability:** none of the ten baseline series triggers the implemented WECO rules. With only 11-12 points, that is weak evidence of stability. The reported alarms are nominal diagnostics, not calibrated tests of causal effects.
- **Uncertainty:** game-bootstrap intervals are omitted for the two insufficient-follow-up cases. Intervals for the other cases are exploratory and omit adjustment-model uncertainty/serial dependence. Michigan State's negative mean-change interval and absence of an SPC alarm answer different statistical questions.
- **Sensitivity:** primary result 1/8 new alarms; sample-SD baseline 0/8; >=40-PPA-observation games 2/8; raw chart 1/8 but a different team; CUSUM h=4 and h=6 each 1/8. This sensitivity prevents a robust coaching-effect claim.
- **Placebos:** 50 distinct team-season units, 48 distinct teams. Matching controls season and approximate timing, not the process that led to firing a coach. Other unrecorded coaching/QB/injury changes may occur. The 14% rate is a placebo alarm rate, not a certified false-positive rate. Its Wilson interval is approximate because observations need not be independent.
- **Review:** seven meaningful unit tests pass. The PDF was rendered and both pages visually inspected. Dashboard logic is tested in an isolated DOM harness; browser rendering could not be verified because the headless browser exits and the in-app browser cannot reach the local server. Native Tableau rendering and the Texas A&M selector were verified. The Tableau Public dashboard is published and its live page was checked.
