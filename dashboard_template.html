What supports this conclusion—and what limits it

Coverage

Overtime, FCS matchups, kneels, spikes, penalties, special teams and garbage time are excluded. Garbage time means a fourth-quarter margin above 28 using the preceding observed score. Missing PPA is never treated as zero.

Reproduce

Executed notebook · Analysis protocol · Dated intervention sources · Data audit

Limits

Small game samples, roster changes, old defensive-strength estimates and simultaneous staff changes limit interpretation. Placebo dates are not proven change-free. A nominal alarm is not a causal finding, and a missing alarm is not evidence that nothing changed.

The prior Texas A&M pilot was inspected before the expanded plan was written. This is a transparent retrospective analysis, not a preregistered experiment.
